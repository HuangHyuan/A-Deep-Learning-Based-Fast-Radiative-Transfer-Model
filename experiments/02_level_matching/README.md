# 37-level and 137-level matched experiments

- `run_matched_input.py`: 37-to-37, 137-to-137 and optional 37-to-137 truncation experiments.
- `train_original_bt.py`: trains the original GB_model architecture on matched data.
- `evaluate_original_matched.py`: evaluates original L37 checkpoints on the matched revision test set.

Set `QJRMS_DATA_L37`, `QJRMS_DATA_L137`, `QJRMS_MODEL_DIR` and `QJRMS_RUNS_DIR` before running.
