# Jacobian computation and evaluation

- `compute_five_station_jacobian_full.py`: computes five-station profile Jacobian statistics.
- `run_all_profiles_jacobian_local.py`: batch Jacobian aggregation for all profiles.

The scripts read data through `QJRMS_DATA_DIR`, `QJRMS_JMATRIX_DIR`, `QJRMS_MODEL_DIR` and `QJRMS_RUNS_DIR`.
